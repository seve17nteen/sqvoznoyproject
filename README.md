\# sqvoznoyproject (Трекер сна)



Сквозной проект по дисциплине «Программирование на Qt». Тема: Трекер сна.

Каркас приложения (Этап 1 и начало Этапа 2).



\## Возможности

\- Главное окно (`QMainWindow`) с меню, панелью инструментов и статус-баром.

\- Форма добавления записей (дата, время засыпания, время пробуждения).

\- Отображение данных в таблице (`QTableWidget`).

\- Валидация ввода (проверка на пустые поля).

\- Демонстрация дерева объектов Qt и `setParent(nullptr)` (Лабораторная работа №2).



\## Требования

\- Qt 5.x или Qt 6.x (модуль Widgets)

\- Компилятор C++17



\## Сборка и запуск

```bash

qmake sqvoznoyproject.pro

make        # или mingw32-make / nmake

./sqvoznoyproject
